# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-03

### Added

- Initial open-source release of Owlery — a self-hosted email platform powered by Amazon SES
- SvelteKit dashboard for domains, templates, campaigns, and queue management
- REST API at `/api/v1/*` with API key authentication
- Background worker for email delivery and webhook processing
- Docker deployment with web + worker supervisor
